# GovPay Riconciliazioni API

[![GitHub](https://img.shields.io/badge/GitHub-link--it%2Fgovpay--riconciliazioni--api-blue?logo=github)](https://github.com/link-it/govpay-riconciliazioni-api)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

API REST Spring Boot per la **riconciliazione dei pagamenti** di GovPay.

## Cos'è GovPay Riconciliazioni API

GovPay Riconciliazioni API è un componente del progetto [GovPay](https://github.com/link-it/govpay).

### Funzionalità principali

- Supporto multi-database: PostgreSQL, MySQL/MariaDB, Oracle, SQL Server
- Health check e metriche Prometheus tramite Spring Boot Actuator, su porta dedicata

## Versioni disponibili

- `latest` - ultima versione stabile

Storico completo delle modifiche consultabile nel [ChangeLog](https://github.com/link-it/govpay-riconciliazioni-api/blob/main/ChangeLog) del progetto.

```bash
docker pull linkitaly/govpay-riconciliazioni-api:latest
```
